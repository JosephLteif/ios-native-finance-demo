Pocket Ledger support

Report a problem or request an improvement through the project’s GitHub issue tracker.

Open GitHub Issues

What to include

  • Your device model and iOS or watchOS version.
  • The app build or GitHub commit, if you know it.
  • Steps to reproduce the issue and what you expected to happen.
  • A redacted error message, if one appears.

Keep financial details private

GitHub issues are public. Never post account numbers, balances, transaction descriptions, receipts, backups, passwords, Apple IDs, or screenshots containing private financial information. Remove or obscure personal details before sharing logs or images.
